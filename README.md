# Datheon_Machine_Learning_-_Data_Science_Internship.


This repository contains four end-to-end machine learning projects completed as part of the Datheon internship program. Each project demonstrates a different area of ML: supervised classification, regression, imbalanced ensemble learning, and natural language processing.

---

##  Project Structure

### 1. Iris Multi-Class Classification
- **Goal:** Benchmark classification pipeline with Scikit-Learn.
- **Techniques:** StandardScaler, Logistic Regression, Decision Tree, Confusion Matrices, ROC Curves, Decision Boundary Visualization.
- **Dataset:** Iris (150 samples, 3 classes).

### 2. California Housing Price Prediction
- **Goal:** Continuous regression modeling with feature engineering.
- **Techniques:** SimpleImputer, StandardScaler, Ridge, Lasso, GridSearchCV, Residual Analysis.
- **Dataset:** California Housing (20,640 samples).

### 3. Telco Customer Churn Prediction
- **Goal:** Solve severe class imbalance and optimize ROC-AUC for churn prediction.
- **Techniques:** SMOTE, OneHotEncoder, Pipeline, Random Forest, XGBoost, Feature Importances, ROC-AUC Curves.
- **Dataset:** Telco Customer Churn (7,043 samples).

### 4. NLP Sentiment Classification on Customer Reviews
- **Goal:** Classify raw text into positive/negative sentiment.
- **Techniques:** NLTK (stopwords, lemmatization), TF-IDF Vectorizer, Multinomial Naive Bayes, Logistic Regression, Custom `predict_sentiment()` function.
- **Dataset:** Sentiment Reviews (small starter dataset).
